# Sammy’s Apps

I’m Samantha Archer Stoltz, a biomedical researcher and software builder. I started building software because lab work kept teaching me the same lesson: doing the work is hard enough. The person who comes after you shouldn’t have to reconstruct how you did it.

This is an index of my prototypes, tools, and design explorations. The underlying code and workspaces are not included here.

## Start with SciOps

A year after an experiment, a file called `run2_new` tells you almost nothing. SciOps is a research workspace I started building so a graph could lead back to the raw data, the exact run, what changed, and who logged it.

The private release candidate uses a React and TypeScript workspace with a Python backend. Its recorded regression run passed 873 automated checks across the backend, workspace, and hosted demo and pilot. That’s a development milestone, not a production launch. I demonstrated the prototype at Kennedy Space Center. The next pilot question is simple: if two runs both export a file called `results.csv`, can someone new start at the graph and find the right file without asking the original team?

## Two related projects

- **ConScience · Private prototype.** A workspace for keeping evidence and interpretation separate when reading scientific research. The current version organizes sources and notes. AI-assisted comparisons are a direction for the product, not a capability I’m claiming for this version.
- **In the Loop · Private demo.** A workflow handoff tool for teams. The idea is to turn a process someone chooses to document into a guide the next person can use. The demo and local pilot backend are early builds.
